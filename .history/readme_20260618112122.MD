## Requirements

Python 3.8+
Python packages: igraph, numpy, scipy, sklearn, pandas, 

For the HRG implementation, we require the PyHRG library.
Install with:

pip install git+https://github.com/RensDeWit/PyHRG'

## Description of classes

dendrogram_generator.py contains the function to generate the dendrogram/HRG.
HMI.py contains the functions to calculate the HMI function.
