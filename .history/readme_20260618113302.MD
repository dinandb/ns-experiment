## Description of classes

dendrogram_generator.py contains the function to generate the dendrogram/HRG.

HMI.py contains the functions to calculate the HMI function.

run_and_compare.py can be used to run a specified experiments, with hardcoded algorithms used, number_dendrograms, n_graphs, n_nodes.

superalgorithm.py is the superclass that all algorithms implement. It has functions 'run' (takes a graph, returns a dendrogram), and 'optimize_for_modularity' (takes a graph and dendrogram, returns the optimal partition to optimize modularity among all possible cuts of the dendrogram, together with the attained modularity).

In the algorithms folder, we provide the implementations of the benchmarked algorithms. They are all subclasses of the SuperAlgorithm.

In the experiments folder, we provide our programs that we used in the statistical analysis and when plotting our results.
experiment.py contains the main experiment that we ran. 
This program is parallelized, but still took about 10 hours to run on our machine.
